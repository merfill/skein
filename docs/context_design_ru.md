# Skein — проектирование контекста (свёрнуто)

> Английское зеркало — `docs/context_design.md`.

> **Свёрнуто в `docs/ir_semantics_ru.md` §7 и `docs/projection_ru.md`.** Этот документ
> описывал проекцию как рабочую память с планом, контейнером `alternatives`, индексом `calls`
> и ограниченным рабочим множеством `shown`. Ревизия заменила всё это: контекст — простая
> **лента сообщений**, собираемая из дерева, без отдельных блоков. Содержимое оставлено лишь
> как указатель; не считай его актуальным.

Что изменилось:

- **план** — узел `plan` над `item`; каждый пункт держит альтернативы (`alts`); закрытие цели —
  связь на цели, а не пункт плана;
- **контейнер `alternatives`** убран — контейнером стал сам пункт;
- **индекс `calls`** и **рабочее множество `shown`** убраны — память и есть история (лента), а
  тело результата достаётся по `id` через `recall`/`search`;
- **немонотонный срез** происходит только при закрытии цели (её внутренние сообщения уходят из
  ленты).

См. `docs/ir_semantics_ru.md` §7 и `docs/projection_ru.md`.
