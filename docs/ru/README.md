# Skein — документация (русский)

## Что такое Skein

- [concepts.md](concepts.md) — концептуальный обзор: немонотонный контекст, четыре агента,
  состояния и переходы.
- [walkthrough.md](walkthrough.md) — сквозной пример: состояния и динамическая лента в разных
  контекстах исполнения.

## IR (источник истины движка)

- [ir.md](ir.md) — концептуальная модель IR: журнал, состояния и переходы, записи, проекция
  контекста и инварианты.
- [ir_operations.md](ir_operations.md) — поверхность модели, операторы, подробные таблицы
  инструментов, отказы и реестр покрытия (`OP-MV`, `OP-CG`, `OP-AP`, `TR`, `DER`, `REF`, ...).
  Проверка полноты покрытия читает этот файл; держите id синхронными с тестами.
- [projection.md](projection.md) — проекция контекста: что модель видит каждый ход и почему.
- [tools.md](tools.md) — контракт инструментов.
