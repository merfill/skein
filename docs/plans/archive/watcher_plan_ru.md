# Skein — план наблюдателя (наблюдение по отпечатку файла)

> Английское зеркало — `docs/plans/archive/watcher_plan.md`.

Связанные: `docs/plans/observation_plan_ru.md` (§8), `docs/concepts_ru.md`
(первый принцип), `docs/ir_ru.md` §5. Общий план —
`docs/plans/implementation_plan_ru.md`.

Статус: реализован (см. §7).

## 1. Проблема

`reconcile` (`src/loop/observe.ts`) на каждом ходу заново хэширует все активные
`ref`. Обнаружение корректно, но неизменённые файлы перечитываются. Наблюдатель
файловой системы предлагался, чтобы замечать изменения быстрее.

## 2. Решение

Сначала наблюдать **отпечаток** файла, хэшировать только если отпечаток изменился.

- `Workspace.signature(path)` — дешёвый заменитель содержимого:
  `mtime + ctime + размер`.
- `reconcile(state, workspace, cache?)` держит кэш
  `путь → { signature, version }`. Если текущий отпечаток равен сохранённому,
  используется сохранённая версия без хэширования; иначе файл хэшируется,
  отпечаток обновляется и версия сравнивается.
- Кэш живёт в течение одного прогона агента (создаётся в `compileGraph`). Без
  кэша `reconcile` хэширует каждый активный `ref` — прежнее поведение.

Наблюдатель файловой системы (`fs.watch`) намеренно **не** реализуется. Цикл
синхронный, и между ходами нет простоя, где можно было бы принять асинхронные
события, поэтому watcher был бы прочитан на той же границе хода, которую уже
покрывает `reconcile`; ему место в будущем стриминговом/простаивающем режиме.

## 3. Дизайн

- `src/tools/workspace.ts` — `signature(path)`: `statSync` → `mtime/ctime/size`.
- `src/loop/observe.ts` — необязательный `VersionCache`; при совпадении отпечатка
  берётся сохранённая версия, иначе — хэш.
- `src/loop/graph.ts` — один кэш на прогон, передаётся в `reconcile`.

## 4. Проверка

- `npm run typecheck`; `npm test`.
- Тесты (workspace со счётчиком): один хэш на первом `reconcile`, ни одного на
  неизменённом втором, повторный хэш и `mutate` после изменения; путь без кэша
  по-прежнему работает.

## 5. Инварианты

- Дрейф по-прежнему обнаруживается; отпечаток лишь пропускает хэш, когда не
  изменился.
- `project` остаётся чистым; наблюдение — шаг цикла.
- Журнал остаётся append-only.

## 6. Границы

- Отпечаток — заменитель: изменение содержимого, сохранившее `mtime`, `ctime` и
  размер, не будет замечено — принято, как в git; при необходимости можно
  добавить принудительный пересчёт.
- `fs.watch` — будущий стриминговый/простаивающий режим.
- Остаётся `stat` каждого активного `ref` на ход.

## 7. Статус

Реализовано. `Workspace.signature` (`src/tools/workspace.ts`); кэш и пропуск
хэша в `reconcile` (`src/loop/observe.ts`); один кэш на прогон
(`src/loop/graph.ts`). `npm run typecheck` чист, `npm test` проходит. Доки
обновлены: `docs/ir_ru.md` §5.
