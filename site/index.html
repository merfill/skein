A coding agent whose context is a projection of its IR.

Skein does not replay a growing message tape. The executor records a typed event journal; every turn rebuilds the model's context from that journal. The model proposes, the executor records, and the journal is the protocol.

View source Install

The npm package and Docker image are published after acceptance. Until then, install from a source checkout as shown below.

How it works

Journal, not tape

Events are appended to a monotone typed IR. Nodes are never rewritten, so the full history stays addressable even when it is not shown.

Projection, not memory

The prompt is rebuilt from scratch each turn. Content can leave the view as the focus moves, while recall and search still reach it.

States with a goal

Work moves through states such as Research, Patch, Construction and Verification. Each has an explicit goal and completion condition, and closes by the model's text.

Install

Requires Node.js 22 or newer.

Linux / macOS

git clone https://github.com/merfill/skein.git
cd skein
npm install
npm run build
npm pack
npm install -g ./skein-swe-*.tgz
skein --version

Windows: bash required

The agent's shell tool runs /bin/bash, so Node must run in an environment that provides it.

  • WSL2 (recommended): install Ubuntu, then follow the Linux steps inside it. Keep projects in the WSL filesystem (~/project), not under /mnt/c.
  • Git Bash / MSYS2: works when /bin/bash is reachable from the shell that launches skein.
  • Docker Desktop: run the Linux image below.

Native PowerShell or cmd without bash is not supported.

Docker

git clone https://github.com/merfill/skein.git
cd skein
docker build -t skein:0.1.0 .
docker run --rm -it \
  -v "$HOME/project:/workspace" \
  -e SKEIN_API_KEY=... \
  -e SKEIN_MODEL=... \
  skein:0.1.0

The provider is passed with environment variables; no model is bundled. On Windows PowerShell use ${HOME} for the mount path.

Configure

Point Skein at a provider with the interactive setup, or with environment variables:

skein auth login     # provider, masked key, model
skein doctor         # checks the key and the model
skein --dir ~/project
export SKEIN_API_KEY=...
export SKEIN_MODEL=...
skein

Local runtimes such as Ollama, LM Studio and vLLM work through --base-url. See the providers guide in the documentation.
