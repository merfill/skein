Skein
GitHub Документация English

v0.1 · исходники

Кодирующий агент, чей контекст — проекция его IR.

Skein не переигрывает растущую ленту сообщений. Исполнитель пишет типизированный журнал событий, и каждый ход заново собирает контекст модели из этого журнала. Модель предлагает, исполнитель записывает, журнал — протокол.

Исходники Установка

npm-пакет и Docker-образ публикуются после приёмки. До этого ставьте из checkout репозитория, как показано ниже.

Как это устроено

Журнал, а не лента

События дописываются в монотонный типизированный IR. Узлы не переписываются, поэтому вся история остаётся адресуемой, даже когда не показана.

Проекция, а не память

Промпт собирается заново на каждом ходу. Содержимое может уходить из вида при смене фокуса, но остаётся достижимым через recall и search.

Состояния с целью

Работа идёт через состояния Research, Patch, Construction, Verification и другие. У каждого явная цель и условие завершения; закрывается оно текстом модели.

Установка

Нужен Node.js 22 или новее.

Linux / macOS

git clone https://github.com/merfill/skein.git
cd skein
npm install
npm run build
npm pack
npm install -g ./skein-swe-*.tgz
skein --version

Windows: нужен bash

Shell-инструмент агента запускает /bin/bash, поэтому Node должен работать там, где он есть.

  • WSL2 (рекомендуется): поставьте Ubuntu и повторите шаги для Linux внутри неё. Проекты держите в файловой системе WSL (~/project), а не в /mnt/c.
  • Git Bash / MSYS2: работает, если /bin/bash доступен из той оболочки, которая запускает skein.
  • Docker Desktop: запустите Linux-образ ниже.

Нативные PowerShell и cmd без bash не поддерживаются.

Docker

git clone https://github.com/merfill/skein.git
cd skein
docker build -t skein:0.1.0 .
docker run --rm -it \
  -v "$HOME/project:/workspace" \
  -e SKEIN_API_KEY=... \
  -e SKEIN_MODEL=... \
  skein:0.1.0

Провайдер задаётся переменными окружения; модель в образ не встроена. В Windows PowerShell для пути монтирования используйте ${HOME}.

Настройка

Укажите провайдера интерактивно или переменными окружения:

skein auth login     # провайдер, скрытый ключ, модель
skein doctor         # проверка ключа и модели
skein --dir ~/project
export SKEIN_API_KEY=...
export SKEIN_MODEL=...
skein

Локальные рантаймы вроде Ollama, LM Studio и vLLM подключаются через --base-url. См. руководство по провайдерам в документации.
